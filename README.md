# Efeose Isibor — Surface Pattern Design Portfolio

Welcome to my personal portfolio website!

This project showcases my creativity and passion for surface pattern design. It features a collection of unique patterns, design applications, and the creative services I offer as a surface pattern designer.

## 🌿 About the Project

This portfolio website was designed to present my creative work, highlight my skills, and provide an easy way for potential clients and collaborators to connect with me.

The website features a clean, elegant design with an emerald green and gold color theme, reflecting my creative identity and design style.

## ✨ Features

* **Home:** An introduction to my work and creative identity.
* **Portfolio:** A showcase of my surface pattern designs.
* **Applications:** Displays how my patterns can be applied to different products and materials.
* **About:** An introduction to me, my background, and my creative journey.
* **Services:** Highlights the design services I offer.
* **Contact:** Provides ways for visitors to get in touch with me.
* **Responsive Navigation:** Includes a mobile-friendly hamburger menu.
* **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
* **Interactive Elements:** Includes hover effects and interactive navigation.

## 🛠️ Technologies Used

* **HTML5** – For structuring the website.
* **CSS3** – For styling, layouts, animations, and responsive design.
* **JavaScript** – For interactive functionality, including the mobile navigation menu.

## 🚀 Getting Started

To view this project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd efeose-portfolio
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in Visual Studio Code for a better development experience.
